## Ezcord Light

A bright variant perfect for daytime coding with softened, readable colors.

## 📥 Installing

1. Open **Extensions** in VS Code (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Search for **`Ezcord Theme`**
3. Click **Install**
4. Open Command Palette → `Preferences: Color Theme`
5. Pick your variant:

```
Ezcord Dark         ← cyberpunk classic
Ezcord Light        ← bright & clean
```
